# Get a PDF (3 steps)

Do **only** this if you want a PDF of the slide deck:

1. **Find this file on your computer:**  
   `docs/community-demo/deck.html`  
   (Inside your Gunanuvad project folder.)

2. **Open it in Google Chrome:** double-click `deck.html`, or drag it into a Chrome window.  
   (Safari also works; Chrome is just reliable for printing.)

3. **Save as PDF:** press **⌘P** (Mac) or **Ctrl+P** (Windows) → where it says **Printer**, choose **Save as PDF** → click **Save**.

That’s it. You do **not** have to add screenshots first — missing pictures show as a small placeholder and the PDF still works.

---

### Optional: add your phone screenshots later

If you want real app pictures in the PDF, save images into the folder  
`docs/community-demo/screenshots/`  
using the exact names listed in `screenshots/README.md`. Then repeat steps 2–3 above.

---

### If you prefer Google Slides instead of a PDF

Open **`MananChintan-Community-Deck.md`**, copy each **“## Slide …”** section onto one slide in Google Slides, and paste screenshots where you like.
